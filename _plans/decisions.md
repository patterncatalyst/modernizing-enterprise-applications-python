| DRQ-026 | **Strangler proxy realized as a Starlette + `httpx.AsyncClient` streaming ASGI reverse-proxy on `:8888`** (realizes the façade named in DRQ-019), with full-path content-based routing on `/api/reviews` and verbatim status/header/body pass-through (never raising on 4xx/5xx upstream). **Buffered-body decision:** the proxy buffers the inbound request body (`content = await request.body()`) and forwards it with a correct `Content-Length` rather than streaming it unread — streaming left `httpx` sending `Transfer-Encoding: chunked` with no `Content-Length`, which the monolith's Django/WSGI stack reads as an empty body, so every `POST` routed through the proxy silently arrived empty. The in-process routing tests (`httpx.ASGITransport`) didn't catch this; it only surfaced when the Newman suite ran against the real WSGI server over a real socket.
