What this book is

A single continuous shipping/e-commerce narrative: build a believable Django monolith with six bounded contexts — order, inventory, payment, shipping, notification, review — then strangle it to FastAPI microservices one seam at a time, in rising order of difficulty. Each pattern (ACL, CDC, outbox, saga, CQRS, service mesh) is introduced at the moment the migration forces it, every extraction is proven against the monolith's own behavior-equivalence suite before its app is decommissioned, and the whole thing is executed through an Agentic Development Lifecycle (ADLC) — a disciplined Frame → Map → Plan → Generate → Verify → Operate → Reconcile loop with explicit human gates.
